# Mohamed Elsayed Hafez Adam — Executive Portfolio & Verified Performance Dossier

A high-converting, modern executive portfolio and performance marketing dossier for **Mohamed Elsayed Hafez Adam** — Head of Advertising managing EGP 500K+/month and Founder of Adams Analytics (Official Meta Tech Provider).

Deployed live: [Vercel Deployment](https://portfolio-landing-page.vercel.app/)

## 🚀 Key Highlights & Architectural Strengths

- **100% Machine-Verifiable Media Track Record**: Reconciled directly from **Meta Marketing API v21.0** across 112 ad accounts, 85 brands, 26 Business Managers, and 74 brand pages ($256,515 USD managed ad spend, 260.5M impressions, 10.1M clicks, 676K+ messaging conversations).
- **Official Meta Tech Provider Platform**: Full showcase for **Adams Analytics** (`meta.buildincairo.com`), engineered end-to-end solo using Next.js, TypeScript, Prisma, MySQL, and Claude Code. Features an interactive gallery of 55 real platform interface screens.
- **Bilingual & Native RTL Architecture**: Instant switching between English and Arabic with dedicated typography (`Inter`, `Plus Jakarta Sans`, and `Cairo`), layout inversion, and complete linguistic translations.
- **Dynamic Growth & ROI Estimator**: Interactive calculator allowing prospective clients to simulate reach, CAC benchmarks, CPM/CPC ranges, and channel allocation across Middle Eastern (Egypt, Saudi Arabia, Qatar, UAE) and global markets.
- **24-Page Official Audit PDF Reader**: In-browser document reader for inspecting every page of the official Meta Marketing API performance record.
- **Searchable Brand Directory**: Instant search and industry filtering across all 85 identified client brands and accounts.
- **Dark & Light Mode**: Bespoke UI styling with custom glows, glassmorphism, and responsive design.

## 🛠 Tech Stack

- **Framework**: React 19 + Vite 7
- **Styling**: Tailwind CSS v4 + Custom Modern Glass Design System
- **Icons**: Lucide Icons
- **Interactions**: Canvas Confetti
- **Typography**: Inter, Plus Jakarta Sans, Cairo (Google Fonts)
- **Deployment**: Vercel (Vite preset with clean URLs and SPA rewrites)

## 📦 Run Locally

```bash
# Clone the repository
git clone https://github.com/adamit20002/portfolio-landing-page.git

# Navigate into project directory
cd portfolio-landing-page

# Install dependencies
npm install

# Start local development server
npm run dev
```

## 🏗 Build for Production

```bash
npm run build
npm run preview
```

## 📜 Provenance & Audit Integrity

Every figure in this dossier is pulled directly from the Meta Marketing API on 08 September 2026.
